# فونت وزیرمتن

سه فایل زیر را در همین پوشه قرار بده:

- `Vazirmatn-Regular.woff2`
- `Vazirmatn-Bold.woff2`
- `Vazirmatn-ExtraBold.woff2`

منبع: مخزن رسمی Vazirmatn (لایسنس SIL OFL، استفاده تجاری مجاز).

مهم: از CDN گوگل فونت استفاده نکن. هم در ایران قابل دسترس نیست،
هم اپ باید بدون اینترنت کامل کار کند.

برای کم کردن حجم (توصیه می‌شود)، فقط کاراکترهای فارسی و لاتین پایه را subset کن:

```bash
pip install fonttools brotli
pyftsubset Vazirmatn-Regular.ttf \
  --unicodes="U+0600-06FF,U+200C,U+0020-007E,U+FB8A,U+067E,U+0686,U+06AF" \
  --flavor=woff2 --output-file=Vazirmatn-Regular.woff2
```

## وضعیت نسخه فعلی

مخزن رسمی وزیرمتن این است:
`https://github.com/rastikerdar/vazirmatn`

در محیط ساخت فعلی، دسترسی مستقیم برای دریافت فایل باینری گیت‌هاب برقرار نبود؛
برای همین دو فایل `NotoSansArabic` به‌عنوان جایگزین آفلاین داخل پروژه قرار گرفته‌اند.
اگر برنامه‌نویس به اینترنت دسترسی دارد، سه فایل رسمی وزیرمتن را از آخرین بسته انتشار
همین مخزن دانلود کند و کنار این دو فایل قرار دهد. بعد از آن، فونت رسمی به‌صورت خودکار
در اولویت قرار می‌گیرد.
